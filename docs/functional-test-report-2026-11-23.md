## 三、发现并修复的 4 个 bug

### P0：bare 仓库完全不可用

**现象**：

```
$ gitannals /srv/git/project.git
✗ 不是 Git 仓库：/srv/git/project.git
```

**原因**：`resolve_repo` 只用 `rev-parse --show-toplevel` 找仓库根。bare 仓库没有工作树，这条命令必然失败——但它其实是合法 Git 仓库，`git log` 照样能读。

**影响范围比想象中大**：CI 里的缓存仓库、`git clone --mirror` 的镜像、服务端部署的仓库，全是 bare。这类用户装完工具会发现「一条命令都跑不了」。

**修复**：`--show-toplevel` 失败时回退到 `rev-parse --git-dir` + `--is-bare-repository`，确认是 bare 就返回该路径。

**回归**：`test_bare_repository` 构造一个真 bare clone，断言能读出提交。

---

### P1：贡献者「其他人」把机器人算进去了

**现象**：gin 仓库，榜单 12 人 + 其他人 = 2023，但实际真人提交只有 1897。

**原因**：`rest_commits = total - sum(榜单)`。榜单已经把机器人排除了，余量却还是按总数算——多出的 126 次正是 `dependabot` 的提交。

**为什么会露出来**：上一版把机器人从榜单移除了，但忘了余量这条路径。数字单独看都正常，并排放就矛盾。

**修复**：`rest_commits = total - bot_commits - sum(榜单)`。

**验证**：gin 现在 1897 = 1897；`test_contributors_rest_excludes_bots` 钉住。

---

### P1：`.annals.toml` 被 CLI 默认值覆盖

**现象**：配置文件写 `lang = "en"`，命令行不传 `--lang`，报告还是中文。

**原因**：`--lang` 的 Typer 默认值是 `"zh"`，而 CLI 无条件把它塞进 overrides。配置文件读到了，随后被默认值盖掉——**配置系统实际上只有 ignore 一项能用**。

```python
# 修复前
lang: str = typer.Option("zh", "--lang")   # 永远非空
overrides={"lang": lang, ...}              # 永远覆盖

# 修复后
lang: str | None = typer.Option(None, "--lang")
overrides={**({"lang": lang} if lang else {})}
```

`tone` 有同样的问题，一起修了。

**回归**：`test_config_lang_survives_cli_default` 验证「不传 → 用 toml；传 zh → 只覆盖 lang，tone 仍用 toml」。

---

### P2：两个同名异常类

**现象**：`analyze.AuthorLookupError` 和 `features.profile.AuthorLookupError` 是两个不同的类。调用方按后者捕获，前者会穿透。

测试里就踩到了：明明报错信息正确，`except AuthorLookupError` 却不进分支。

**修复**：`analyze` 直接复用 features 的类，删掉重复定义。

### 一条数据完整性改进

`overview` 的三个计数并排出现时，读者一定会加总：

```
总数 2023 = 代码 1789 + merge 216 + ？
```

差额 18 是「既非 merge、又没有文件变更」的提交（空提交 / 只改了噪音文件）。之前这个差额无处安放，三个数加起来对不上。

新增 `commits_empty` 字段，现在 `2023 = 1789 + 216 + 18` 成立。

## 四、两项「疑似失败」其实是测试写错

这两条值得单独记，因为它们是**测试本身不可靠**的典型。

**1. 英文版里出现 2 个汉字**

```
<span class="pname" title="thinkerou@gmail.com">田欧</span>
```

第一反应是 i18n 漏了。追下去发现 `田欧` 是**作者的显示名**——数据不该被翻译。

断言改为：在**全英文人名**的仓库（type-fest）上跑英文版，汉字必须为 0。

**2. 匿名画像「泄露」仓库名 gin**

```
'webkit-text-size-adjust:100%}\n  body{\n    margin:0; ...'
```

`gin` 匹配到了 CSS 里的 `margin` 和 `webkit`。三字母探针在 CSS 里几乎必然误报。

改为先剥掉 `<style>` 再搜，并且用完整仓库名 `gin-gonic` + 作者姓名做探针。实测仓库名已正确替换为 `repo-3cd1e3`。
